# Cadastro de Clientes (CRUD) — Java + DAO em Memória

Projeto simples em Java para **cadastrar, consultar, atualizar e excluir clientes**, usando o padrão **DAO** com armazenamento **em memória** (sem banco de dados).  
A interface é feita com **JOptionPane (Swing)**, ideal para estudos de **POO**, **Collections** e **arquitetura em camadas**.

---

## Funcionalidades

- **Cadastrar cliente**
- **Consultar cliente por CPF**
- **Alterar dados do cliente**
- **Excluir cliente por CPF**
- Estrutura baseada em:
  - `domain` (entidades)
  - `dao` (contratos e implementações)

---

## Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Collections (`Map`, `Set`)
- Interface + Implementações (`IClienteDAO`)
- Padrão DAO
- Encapsulamento, `equals/hashCode` (por CPF)

---



## Requisitos

- **Java JDK 8+** (recomendado 11+)
- Qualquer IDE (IntelliJ / Eclipse / VS Code) ou terminal
